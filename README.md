# Tic-Tac-Toe

A browser-based Tic-Tac-Toe game for two players, built with HTML, CSS, and JavaScript. The project combines classic X-and-O gameplay with a themed interface, interactive feedback, and a simple score tracker.

## Features

- **Two-player gameplay:** Players take turns placing X and O on a 3×3 board.
- **Win and draw detection:** Automatically identifies winning combinations and draws.
- **Score tracking:** Saves player scores using browser localStorage.
- **Light and dark themes:** Switch between two visual themes.
- **Winning-cell highlights:** Highlights the three squares forming a winning combination.
- **Game controls:** Restart a round or reset both players' scores.

## Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome 6.4.0

## Getting Started

No installation or build tools are required.

1. Clone or download this repository.
2. Open `final project.html` in your browser.
3. Start playing by selecting any square on the board.

## How to Play

1. X starts the game.
2. Players take turns selecting empty squares.
3. The first player to get three matching symbols in a row, column, or diagonal wins.
4. If all nine squares are filled without a winner, the round ends in a draw.
5. Select **Restart Game** to start another round or **ReScore** to reset the scores.
